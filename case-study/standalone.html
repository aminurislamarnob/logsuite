Case study · Cross-platform mobile app

Seven offline-first productivity modules on one SQLite database

Between June and November 2026, I built LogSuite, an offline-first Flutter app that combines tasks, notes, habits, medicine schedules, expenses, a focus timer, and a quick-capture inbox called Drop. Every module reads and writes a local SQLite database through Drift and can be turned off in Settings when a user wants a smaller app. I made all 102 non-merge commits on main, pairing with Claude Code across 76 of them, and backed the codebase with 392 automated tests.

The brief before 29 Jul

What had to be true from the start

From the README and taste rules, five constraints shaped the project:

  • Offline-first persistence: Every module reads and writes a local SQLite database through Drift (lib/core/database/app_database.dart), with no mandatory account or server.
  • Optional modules: Each module can be switched on or off in Settings so the navigation shell and dashboard only show what the user uses.
  • First-class Bangladesh locale: ৳ (BDT) currency, Bangla numerals (০ to ৯), seeded Cash, bKash, Nagad, and Bank accounts, and English/Bangla/Banglish voice parsing.
  • User-owned AI keys: Spoken and scanned commands work with Claude, OpenAI, Gemini, or DeepSeek using an API key kept in the platform keychain, and fall back to an offline parser when no key is set.
  • No dead buttons or half-shipped features: Every toggle, backup action, reminder, and sound option in the UI is wired end to end and covered by tests.
Architecture 29 Jul to 5 Nov

One SQLite database beneath seven modules

The UI sits on go_router nested shells and a shared widget kit in lib/core/widgets/ built over forui primitives. AppColors defines the coral brand accent (#F15F43), a three-way pastel card rotation, and warm per-module tints that pass contrast checks.

Below the screens, Riverpod providers watch 22 Drift SQLite tables (Folders, Notes, Tags, NoteTags, Projects, Tasks, TaskTags, Habits, HabitLogs, People, Medicines, MedicineDoses, SymptomLogs, Accounts, ExpenseCategories, Expenses, Budgets, RecurringExpenses, Loans, FocusSessions, Drops, and DropTags). The AI command executor and the editor sheets write through the same repository methods, so a spoken or scanned entry produces the exact same rows and OS notifications as a typed one.

Expenses & loans 2 to 4 Sep

Expenses: people, loans, and month-scoped budgets

Household spending rarely belongs to one person or stays inside simple income and expense rows. On 3 September I wrote expense-module-plan.md and shipped a 14-commit sequence (0465f94 to 46cafbf) that split expenses_screen.dart into five tab files (Overview, Reports, Budgets, Bills, and Loans) and added a core People table, month-scoped budgets, and a loan ledger.

Editing a transaction reverses its old account delta and applies the new one inside a single Drift transaction (ead7675). Swiping to delete raises an undo toast that re-inserts the row with its original primary key so loanId and receipt links stay intact. Deleting a category or person with history prompts to reassign those transactions rather than orphaning them.

TxKindWhat it recordsEffect on balances and reports
0 · ExpenseSpending attributed to a person (defaults to Self)Subtracts from account; counted in monthly spend and person reports

AI assistant 5 to 13 Sep

Spoken sentences and scanned documents become previewed drafts

Between 5 and 8 September (c77c448 to fae2ac5), and in PR #3 on 13 September (9483453), I built the AI assistant so a single sentence such as *'spent 200 taka on lunch with bKash and remind me to call the doctor at 5, and add Napa 3 times a day for 5 days'* creates an expense, a task with a reminder, and a medicine course.

Speech recognition and ML Kit document OCR always run on the device (speech_service.dart, ocr_service.dart), so audio and photos never leave the phone. The transcript is sent with the action schema (ai_command_schema.dart) and the names of the user's categories, accounts, people, habits, and projects to whichever provider is chosen in Settings: Claude, OpenAI, Gemini, or DeepSeek. The user's API key lives in flutter_secure_storage (platform keychain). Without a key, LocalCommandParser splits clauses on English and Banglish conjunctions (and, then, ar, ebong) and routes each clause to the local task, medicine, and expense parsers.

Sounds, backup & motion 6 to 13 Sep

Click-free WAV loops, all-or-nothing restore, and iOS motion

Three commits in early September closed gaps between what the UI offered and what ran underneath, followed by a full spacing and motion pass in PR #4 (8665585) and the rename from mySuite to LogSuite (caa068b).

Synthesised WAV loops (15cfc3d)
Six 16-bit mono PCM files in assets/sounds/ (rain, ocean, forest, cafe, white_noise, brown_noise) built in the frequency domain with random phase so every buffer is periodic and loops without an MP3/AAC padding click.
All-or-nothing JSON restore (15cfc3d)
RestoreService parses and validates the entire backup file before opening a database transaction, defers foreign keys for self-referencing folders, and decodes base64 profile photos back to local storage.
How-to guides (7f93da7)
Settings -> How to renders collapsible step-by-step cards from how_to_content.dart with a button that opens or enables each module.
Spacing and iOS motion (PR #4)
Unified AppSpacing tokens (gutter 20, section 24, card gap 10), computed bottom clearance from bar height plus safe-area inset, and added Cupertino swipe-back transitions and rubber-band overscroll.
Drop & triage 29 Oct to 6 Nov

Drop: quick-capture inbox, tag autocomplete, and triage gamification

On 29 October I added native Flutter integration tests (integration_test/app_test.dart, commit acfef31). Then on 5 and 6 November I shipped the seventh module, Drop (2ee5f96 to 3953c20, closing issues #5 through #13): a stream for capturing links, YouTube videos, photos, and rough thoughts before deciding where they belong.

  • Rich capture and OS share sheet (#6, #7, #8, #11): Schema v3 migration adds Drops and DropTags, ingests payloads from the native OS share sheet (receive_sharing_intent), scrapes OpenGraph and YouTube metadata for preview cards, downscales thumbnails to 400px, and runs on-device ML Kit OCR on images.
  • Triage, escalation, and summarization (#9, #12, #13): Items can be pinned, bulk-selected, scheduled with 'Remind Me Later' notifications, summarized with AI or extractive fallback, or converted into a Note or Task prefilled in its editor.
  • **WhatsApp-style # tag suggestions (8ffdb49, 9c9f698):** Typing # in the bottom capture bar opens a suggestion card with fuzzy matching over existing tags.
  • **Gamification, haptics, and in-app browser (1dd6ef8, 4d05d73, 3953c20):** Triage actions award XP, build daily streaks, unlock badges, and trigger an Inbox Zero celebration, paired with an app-wide haptics toggle and an in-app browser with external launch fallback.
